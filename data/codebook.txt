ABOUT THE DEPOSITED DATA
------------------------
The de-identified analysis dataset contains 118 questionnaire records and 36
deposited input columns. Each row represents one questionnaire record. The
file used by the main Stata analysis is analysis_data_deidentified.dta; the CSV
file is an open-format copy of the same data.

The two training locations are represented by the neutral labels
"small_town" and "rural_area". These labels do not disclose the actual
locations. A period (.) means that a value is missing.

The Stata analysis script drops the four records that have no one-way mileage,
leaving 114 records before other variable-specific missing values are taken
into account. Part 1 documents the columns stored in the deposited files.
Part 2 documents variables that the Stata script creates during analysis.

PART 2 -- VARIABLES CREATED FOR REPORTED ANALYSES
-------------------------------------------------
The variables in this part are not additional columns in the deposited input
files. The Stata script creates them after loading the data. A 0/1 variable is
a yes-or-no indicator: 1 means the stated condition is met, and 0 means it is
not. A missing source response generally produces a missing constructed value.

Analysis variable [article label]   Meaning, construction, and use
----------------------------------  --------------------------------------------------------------
WTA [WTA, $]                        Lowest payment the respondent said they would accept to attend
                                    the training. It is copied from A_dollars_accept and is the
                                    outcome variable in Tables 1-4 and the article text.

WTP [WTP, $]                        Amount the respondent said they would pay to attend. It is
                                    copied from B_wtp_workshop and is used in Tables 1-2 and the
                                    article text.

WTP_log [Ln(WTP)]                   Natural logarithm of WTP: ln(WTP). It is used in Tables 2-4.
                                    All nonmissing WTP values in the deposited data are greater
                                    than zero.

no_ppl [Npeople, 1-4]               Number of people in the travel party, including the respondent:
                                    "self" = 1, "1 other" = 2, "2 other" = 3, and three or more
                                    others = 4. It is used in Table 1, travel-cost calculations,
                                    and the article text.

mileage [Nmiles, mi]                Reported one-way mileage, copied from travel_miles_class after
                                    records with missing mileage are removed. It is used in Table 1,
                                    travel-cost calculations, and the article text.

total_travelcost [TravC, $]         Estimated round-trip vehicle cost plus the estimated value of
                                    round-trip travel time. A concise calculation summary appears

[AvgKnowBef, 1-5]                   general-topic before items and seven skill before items. If all

ESSENTIAL CONSTRUCTION AND SAMPLE NOTES
---------------------------------------

- total_travelcost combines the respondent's share of round-trip vehicle cost
  with the estimated value of round-trip travel time:

      vehicle-cost share = ((mileage * 2) / no_ppl) * per-mile rate
      travel-time value = (2 * mileage / avg_speed) * (med_hour_wage / 3)
      total_travelcost = vehicle-cost share + travel-time value

  The per-mile rate is $0.62 for 2019 and $0.64 for 2020 and 2021. The script
  treats all small_town records as respondent-paid for this calculation. When
  an organization or employer paid, total_travelcost is set to 0. The exact
  site-specific speed equations and hourly wage assignments by education,
  gender, and year are documented in
  code/WTA_education_analysis_repository.do.

- The four records with missing one-way mileage are removed, reducing the
  analysis data from 118 to 114 records before other variables are created.
  Variable-specific missing values can further reduce the number of records in
  an individual table or model.

- avgknowledge_be and avgknowledge_af average whichever of the relevant 11
  ratings are available for a record. They do not require all 11 ratings to be
  nonmissing; the average is missing only when all 11 ratings are missing.

- The S1 Table robustness comparison uses records with nonmissing values for
  both enhance_success and influ_future.

- The labels in square brackets are assigned by
  code/WTA_education_analysis_repository.do. The relabel_tables.py helper uses
  them in exported tables without changing numeric data cells.

- Supporting variables used only as intermediate calculation steps are not
  listed separately. Their exact definitions and implementation are documented
  in code/WTA_education_analysis_repository.do. Temporary sample markers,
  residuals, predicted values, and stored estimation objects are also omitted.

- All formulas, mappings, article labels, and result locations describe the
  de-identified data and analysis script included in this repository.
