DOCUMENTATION FILES
-------------------
The files in this folder accompany the PLOS ONE article.

S1_Appendix.pdf
    Blank survey instrument supplied to PLOS ONE as S1 Appendix.

S1_Table.pdf
    S1 Table reference copy: the perceived-benefit robustness check. The main
    Stata analysis reproduces the underlying results; see "WHERE TO FIND EACH
    REPORTED RESULT" in README.

S2_Table.pdf
    S2 Table reference copy: distributions of the two perception items.
    Reproduced by code/reproduce_S2_and_shares.do.

Data_Availability_Statement.txt
    Data Availability Statement identifying the public Zenodo record and
    explaining the materials withheld to protect participant and
    training-location privacy.

README_docs.txt
    This guide to the documentation folder.
